## Controle de Despesas Rápidas

Um aplicativo web simples e funcional para gerenciar despesas do dia a dia, desenvolvido com HTML, CSS e JavaScript puro.

## ✨ Funcionalidades

- ➕ **Adicionar despesas** com descrição, valor e categoria (alimentação, transporte, lazer ou outros)
- 🗑️ **Excluir despesas** da lista rapidamente
- 📊 **Cards resumo**:
  - Total gasto hoje
  - Total da semana (últimos 7 dias)
  - Média diária de gastos na semana
  - Maior despesa do dia
- 📈 **Gráfico de barras** mostrando distribuição dos gastos por categoria nos últimos 7 dias
- 💾 **Persistência local** – os dados são salvos automaticamente no `localStorage` do navegador
- 📱 **Design responsivo** – funciona bem em desktop, tablet e dispositivos móveis

## 🚀 Como usar

1. Faça o download dos três arquivos (`index.html`, `style.css` e `script.js`) e coloque-os na mesma pasta.
2. Abra o arquivo `index.html` em qualquer navegador moderno (não é necessário servidor).
3. Adicione suas despesas preenchendo os campos e clicando em "Adicionar despesa".
4. Clique em "Excluir" para remover uma despesa da lista.
5. Feche e reabra a página – seus dados continuarão salvos.

## 🛠️ Tecnologias utilizadas

- **HTML5** – estrutura da página
- **CSS3** – estilização, layout responsivo e gráfico de barras com Flexbox
- **JavaScript (ES6+)** – manipulação do DOM, lógica de negócio e `localStorage`
